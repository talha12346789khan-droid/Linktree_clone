# Internationalization (i18n)

## Locales
`en`, `ur`, `hi`, `ja`, `es`, `ar`, `fr`, `de`, `pt`, `tr`, `zh` — default **en**.

URLs use a locale prefix: `/en/generate`, `/ar/analytics`, etc.

## RTL
Arabic (`ar`) and Urdu (`ur`) set `dir="rtl"` on `<html>`.

## Translated (Phase 1)
- Navbar, Footer, language switcher
- Home, auth/signin, generate, analytics
- Support, profile reviews, app ratings (home section)
- Admin: stats, moderation, support (UI labels/buttons only)

## Not translated (v1)
- **Marketing long-form content** in `lib/content.js` (product/templates/marketplace/learn/pricing pages)
- User-generated content: handles, bios, reviews, support messages, link names
- API error messages (mostly English)

## Add a language
1. Add code to `i18n/routing.js` (`locales`, `localeNames`, `rtlLocales` if needed)
2. Copy `messages/en.json` → `messages/{code}.json` and translate all keys
3. Run `npm run build`
